## Description

We are building a RESTful file storage API (similar to Google Drive) using Go and the Gin Web Framework. Users can register accounts, create folder structures, upload/download files, and share files with other users.

## Prerequisites

Before running the project, ensure you have the following installed:

- **Docker Desktop**
- **Go 1.22+**
- **Git**

## Configuration
